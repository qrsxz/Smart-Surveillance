========================================
智能监控 MVP v4.0 开发环境要求
========================================

一、操作系统
----------------------------------------
- 宿主机：Windows 10/11（用于 VMware）
- 虚拟机：Ubuntu 22.04 LTS（推荐）或 Ubuntu 20.04 LTS

二、虚拟机软件
----------------------------------------
- VMware Workstation Pro 16+ 或 VMware Workstation Player
- 虚拟机配置建议：
  - CPU：2核以上
  - 内存：4GB以上
  - 硬盘：40GB以上
  - 网络：NAT或桥接模式（用于SSH和SCP）

三、开发工具链
----------------------------------------
1. 编译器
   - GCC/G++ 11.0+（支持C++17）
   - 安装命令：apt install build-essential

2. CMake
   - 版本：3.10以上
   - 安装命令：apt install cmake

3. Qt开发库
   - Qt5 或 Qt6（推荐Qt5，兼容性更好）
   - 安装命令：apt install qtbase5-dev qt5-qmake

4. OpenCV
   - 版本：4.x（测试环境为4.10.0）
   - 安装命令：apt install libopencv-dev
   - 验证安装：pkg-config --modversion opencv4

四、摄像头/视频源
----------------------------------------
1. USB摄像头（可选）
   - 即插即用，设备号为 /dev/video0

2. 视频文件
   - 支持格式：MP4, AVI, MKV等
   - 测试视频路径示例：/home/suge/08021/test.mp4

3. RTSP流（可选）
   - 网络摄像头地址，如：rtsp://192.168.1.100:554/stream

五、编译与运行
----------------------------------------
1. 克隆或复制项目到虚拟机
   cd ~/智能监控MVP

2. 创建build目录并编译
   mkdir -p build && cd build
   cmake ..
   make -j4

3. 运行程序
   ./SmartSurveillanceMVP

4. 在界面输入视频源路径，点击"添加并启动"

六、常见问题
----------------------------------------
Q: 编译报错找不到OpenCV
A: apt install libopencv-dev

Q: 编译报错找不到Qt
A: apt install qtbase5-dev

Q: 程序运行后无法打开摄像头
A: 检查摄像头权限或使用sudo运行

Q: 视频播放卡顿
A: 降低视频分辨率或使用更高效的编码格式
