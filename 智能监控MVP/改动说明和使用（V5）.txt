========================================
一、V5 新增功能
========================================

★ 核心功能：局域网实时画面推流

在 V4（运动人物识别 + 计数）基础上，
V5 新增 MJPEG 流媒体服务器，实现：
- 同一局域网内的手机 / 电脑 / 平板
- 无需安装任何软件，浏览器打开网址
- 即可实时观看监控画面（含人物检测框和计数）

========================================
三、StreamServer 工作原理
========================================

技术方案：MJPEG over HTTP（multipart/x-mixed-replace）

流程：
  程序每处理一帧画面
      ↓
  有客户端在看？ ──否──→ 跳过（不编码，省 CPU）
      ↓是
  缩放图片到 640px 宽
      ↓
  编码为 JPEG（质量 70）
      ↓
  以 multipart 流格式推给所有已连接浏览器

限制：
- 帧率上限 10fps（100ms 一帧），防止 CPU / 带宽过高
- 无客户端时不编码，零额外开销
- 同时支持多个客户端同时观看

四、编译方法（虚拟机 Ubuntu）
========================================

前提：安装 OpenCV4、Qt5/6（含 Network 模块）、CMake

  cd ~/智能监控MVP
  mkdir -p build && cd build
  rm -rf *            # 清理旧缓存，必须
  cmake ..
  make -j4
  ./SmartSurveillanceMVP

程序启动后，窗口底部会显示类似：
  局域网: http://10.24.157.126:8081

========================================
五、使用指南
========================================

【一】本机查看（自测）
  程序运行 + 添加视频源后，
  浏览器访问  http://127.0.0.1:8081
  能看到画面 = 推流正常

【二】手机 / 其他设备查看（局域网）
  1. 手机连接【和电脑同一个 WiFi】
  2. 浏览器输入电脑的局域网地址，例如
     http://10.24.157.126:8081
  3. 直接看到实时画面

  怎么看电脑的 IP？
  Windows:   ipconfig   → WLAN 网卡 IPv4
  Linux:     ip addr / hostname -I

【三】虚拟机场景（重要）
  程序跑在 VMware 虚拟机里时，虚拟机通常是
  NAT 模式（如 192.168.136.x），外部设备访问不到。

  解决办法（二选一）：

  方案1：Windows 端口转发（推荐，SSH 不变）
    以管理员身份运行 PowerShell：
      netsh interface portproxy add v4tov4 ^
        listenport=8081 listenaddress=0.0.0.0 ^
        connectport=8081 connectaddress=虚拟机IP
    防火墙放行：
      netsh advfirewall firewall add rule ^
        name="MJPEG_8081" dir=in action=allow ^
        protocol=TCP localport=8081
    然后手机访问  http://Windows的IP:8081

  方案2：虚拟机改桥接模式
    虚拟机直接拿局域网 IP，手机直连。
    缺点：IP 会变，SSH 地址需重查。

【四】VPN / Clash 注意事项（坑！）
  Clash 等 VPN 开启时会：
  1. 创建虚拟网卡，电脑 IP 会变化（如 10.200.x.x）
  2. 劫持路由，局域网设备可能访问不到

  解决办法：
  - 测局域网访问时，先退出 Clash
  - 或把 Clash 设置为"仅代理浏览器 / 规则模式直连局域网"
  - 别在开 Clash TUN 模式时指望别人能访问

========================================
六、排错速查
========================================

问题1：手机浏览器一直"卡加载"
  查：电脑真实 IP 变了？(ipconfig 重新确认)
  查：Clash 还开着？(先退出)
  查：手机和电脑是不是同一 WiFi？

问题2：本机能访问，手机不行
  防火墙没放行 8081 → 见上面方案1
  手机和电脑不在同一网络

问题3：虚拟机里启动显示 192.168.136.x
  NAT 模式，外面访问不到 → 见上面方案1/2

问题4：编译报找不到 opencv2/videoio.hpp
  CMakeLists.txt 里 ${OpenCV_LIBS} 被写没了
  （注意用文本编辑器保存时别让 ${} 被转义）
